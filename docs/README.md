## Architecture Status

The Nowhere Esports Intranet specification is the target architecture for the next implementation phase. It supersedes the older static-page intranet feature plan and aligns the target application with:

- React, Vite, TypeScript, Tailwind CSS, and shadcn/ui on the frontend.
- Node.js and Express.js on the backend.
- Supabase PostgreSQL, Supabase Auth, Supabase Realtime, and Supabase Storage.
- Docker and Docker Compose for local and production deployment.
- VIGILANCE attack telemetry integration for cyber deception workflows.
