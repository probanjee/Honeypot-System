# Nowhere Esports Intranet  

## Setup
1. Install dependencies: `npm install`
2. Set up environment: Copy `.env.example` to `.env` and fill in values.
3. Seed the database: `npm run seed`
4. Start dev server: `npm run dev`

## Up-coming Features
- JWT + 2FA (OTP) Authentication
- Live Match Ticker (SSE)
- Dashboard with upcoming matches
- Role-based access control (Admin, Coach, Player, Staff)
